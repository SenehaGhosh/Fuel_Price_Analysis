# ⛽ Fuel Price Analysis in India

## 📌 Project Overview
This project analyzes petrol and diesel prices in India using Python. It explores yearly and state-wise fuel price trends through data analysis and visualization using Pandas and Matplotlib.

## 🎯 Objectives
- Analyze year-wise average petrol prices.
- Analyze year-wise average diesel prices.
- Compare petrol and diesel price trends.
- Analyze state-wise average fuel prices.
- Visualize the results using graphs.

## 📂 Dataset
The dataset contains fuel price records from different states and cities in India.

### Features
- Date
- State
- City
- Fuel Price (Rate)

## 🛠 Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib

## 📊 Project Workflow
1. Import libraries
2. Load the datasets
3. Convert the date column into datetime format
4. Extract the year from the date
5. Calculate year-wise average prices
6. Create line chart
7. Create bar chart
8. Analyze state-wise average prices
9. Draw state-wise visualizations
10. Summarize findings

## 📈 Results
- Petrol prices remained higher than diesel prices throughout the analysis period.
- Both petrol and diesel prices showed an overall increasing trend.
- State-wise analysis revealed variations in average fuel prices across India.

## 📷 Visualizations
- Year-wise Average Fuel Price
- Year-wise Petrol vs Diesel Comparison
- State-wise Average Petrol Price
- State-wise Average Diesel Price
